which are free to use under the [Unsplash License](https://unsplash.com/license). The photos are
not stored in this repository (`photos/` is gitignored). Thank you to the photographers!

The files have no EXIF data, so their modification time was set to the date each photo was
published on Unsplash; that is the date the gallery groups and sorts by.
